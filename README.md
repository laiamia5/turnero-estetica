# Sistema de Gestión de Turnos para Estética

## 1. Descripción del proyecto

Sistema web de gestión y autogestión de turnos para una estética, que permite a los clientes registrarse, consultar servicios disponibles, seleccionar horarios y reservar citas mediante el pago de una seña.

**Estado del proyecto:** En desarrollo.

## 2. Objetivos

- Automatizar la gestión de turnos.
- Facilitar la reserva de citas para los clientes.
- Optimizar la administración de horarios y servicios.
- Gestionar los pagos de señas mediante Mercado Pago.

## 3. Funcionalidades principales

- Registro e inicio de sesión de clientes.
- Verificación de cuentas mediante correo electrónico o teléfono.
- Consulta de servicios disponibles.
- Visualización de horarios disponibles y reservados.
- Reserva de turnos.
- Pago de seña mediante Mercado Pago.
- Administración de servicios, horarios y reservas.

## 4. Tecnologías utilizadas

- **Frontend:** React.js
- **Backend:** Node.js y Express.js
- **Base de datos:** PostgreSQL
- **Control de versiones:** Git y GitHub
- **Procesamiento de pagos:** Mercado Pago
